# ADR 007 — GIS 分析ワークベンチ (複数地点比較 UI)

**Date**: 2026-06-28
**Status**: Accepted（dashboard を temp存しつつ、分析重視の GIS ワークベンチを既定 UI に）
**関連**: [004 v2スコア](004_phase2-scoring-v2.md) / [006 冬の光環境スクリーニング](006_winter-light-screen-conclusions.md)

---

## Context

従来の `index.html` は「ダッシュボード」（中央寄せコンテナ + Map/Scatter/Ranking/About のタブ切替）。
1地点ずつしか見られず、**複数地点を重ねて比較**する分析作業に向かない。妻が GIS を使いこなすため、
**マップを土台にした GIS 風ワークベンチ**（地点クリックで選択 → 全ビューで連動ハイライト → 年周カーブ等を重ね描き）が欲しい、という要望。

## Decision

**全画面レイアウトの GIS ワークベンチを新しい `index.html` に。** 既存ダッシュボードは `classic.html` として温存・相互リンク。

- **土台 = Leaflet マップ（全画面）**。上に重みスライダー（hide可）、右に Scatter/Ranking/Compare ペイン（hide可）、下に選択トレイ。
- **選択モデル + linked brushing**: マップのマーカー / 散布図の点 / ランキングの行の**どれをクリックしても地点を選択トグル**（複数可）。選択地点は全ビューで**同じ色**でハイライト、hover も連動。
- **Compare タブ（複数地点を重ね描き）**:
  - 比較表（選択地点を列に、12指標を行に。冬リスク band 色付き。重みでリアルタイム再計算）
  - 年周カーブ（平年値 15日平滑、ソースの単位）
  - 冬の連続曇天（実日別 1991-2020、各暦日の P(日照<2h)）
  - v2 5軸レーダー（desirability d、なぜその順位かの分解）
  - 太陽南中高度 / 昼の長さ（緯度から決定論的に計算）
- **スコアリングロジックは v2/v1 とも従来コードをそのまま再利用**（アンカー・z スコア・非補償集約は [004] のまま無改変）。リアルタイム再ランクも踏襲。

## データ層: `web/series.json`（新規）

Compare の重ね描きに 1 地点あたりの**時系列**が要る。`analysis/export_series.py` が生成:

- `solar` / `sun`: 気象庁の **30年日別平年値**（`data/jma_solar.db` の `daily_data.solar_normal` / `sunshine_normal`、365日）。公表された平年値そのもの。
- `wdark`: **実日別観測 1991-2020 から導出**した「冬の連続曇天確率気候値」＝各冬の暦日(Nov1..Mar31)で日照<2h だった年の割合。

**ライセンス/容量上の判断**: 生の日別観測（`data/jma_daily/`）は再配布条件未確認 + 容量大のため [005]/[006] の方針どおり **gitignore のまま**。`wdark` は生データではなく**集約した気候値（確率曲線）**なので公開可。`series.json` 442KB、初回ロードのみ。
**太陽高度・可照時間はデータ不要**（緯度 + day-of-year から JS で計算）。

## 検証（playwright スモークテスト）

154地点ロード・156地点 series・selection（松本/帯広/金沢）→ Compare 5図とも 3 系列描画・比較表12行・選択行ハイライト3。
w_floor 1→3 で 151/154 の順位が変動（スライダーが効く）。ソース切替で solar に無い松本/金沢が選択から自動除外（帯広のみ残る）。
`wdark` 気候値の物理整合: 松本 0.21 / 帯広 0.17 / **金沢 0.52**（日本海の連続曇天が確率曲線に出る）。

## Notes / Limitations

- 技術スタックは据え置き（Leaflet + Plotly + 素の JS、フレームワーク無し＝GitHub Pages 一枚デプロイ維持）。
- `wdark` は**確率の気候値**で個々の冬の連続日数そのものではない（連続日数の指標は data.json の `dark_spell` CVaR80 を比較表に併記）。
- レーダーの d は重みに依存しない（アンカーで決まる desirability）。順位/スコアのみ重みでリアルタイム変化。
- 居住可能性フィルタ（医療/生活/雪/暑熱）は未統合（[006] の今後課題のまま）。

## 再現
`python analysis/export_series.py` → `web/series.json`。UI は `web/index.html`（classic は `web/classic.html`）。
