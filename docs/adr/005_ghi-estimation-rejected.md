# ADR 005 — 全天日射量(GHI)の推計を検討し不採用、外部GHI(NEDO)へ

**Date**: 2026-06-28
**Status**: Accepted（A–P自前推計は不採用 / 日照時間を主proxy / NEDO外部GHIを候補地監査に）
**関連**: [004](004_phase2-scoring-v2.md)

---

## Context

全天日射量(GHI)は気象庁の実測が**48地点のみ**。一方 日照時間は155地点。移住第一候補の**松本(610m)・諏訪(760m)・軽井沢(999m)など内陸盆地は日照時間はあるがGHIが無い**。GHIで盆地を評価したい。

## 検討した案 (A): Ångström–Prescott による自前推計

`GHI = (a + b·n/N)·Ra`（n=日照時間, N=可照時間, Ra=大気外日射、後2者は緯度・日付から決定論的）。48のGHI実測点で a,b を最小二乗較正（**a=0.22, b=0.54**、日本の文献値 MRI a=0.23/b=0.48 と一致）し、155点全部の推計GHIを生成して第3ソースにする案。

## 実装前のバイアス監査・実験（不採用の根拠）

確証バイアス／局所最適を避けるため、実装前に実データで批判的検証 + 独立第二意見(Codex consult)を実施した。

1. **外挿問題**: 較正集合(GHIあり48点)の標高は**最高418m(長野)止まり**。候補盆地は516〜999mで**全部較正範囲の外＝外挿**。500m超の較正点はゼロ＝高地推計を自前データで検証できない。
2. **標高バイアス(有意)**: 残差(実測−予測) vs 標高 = **+2.0 MJ/1000m (r=0.33, p=0.02)**。A–Pは高地を系統的に誤推定（標高項を足しても係数自体が418m超では外挿・未検証）。Codexの指摘: この残差は標高でなく内陸性・盆地霧・積雪反射・観測点分布の代理かもしれず、補正先が誤っている恐れ。
3. **実験(推計GHIで盆地はどこへ)**: 松本 日照#10→推計GHI#31、軽井沢 #16→**#1**、飯田 #64→#6 と**外挿の数値で順位が乱高下**。推計GHIランキングの**上位が軒並み「外挿(高地)」フラグ＝最も信用できない数字が最上位に来る**。productに載せれば誤誘導。
4. **しかしGHI≠日照(重要)**: 当初「推計GHIは日照とr=0.96で情報増えない」と考えたが、これは*推計GHI vs 真GHI*の比較で自明に高いだけだった。**日照 vs 真GHI**を重複47点で比べると **Kendall-τ=0.64・top10一致5/10**、実測の名古屋が 日照#59→真GHI#10。→ **proxy選択は結論を左右する本物の判断**で、GHIは日照の冗長コピーではない。だが**推計GHIは盆地で信用できない**。

## Decision

- **(A) A–P自前推計GHIはランキングに採用しない**。記録・感度参照のみ（`analysis/` の実験スクリプトとして残置）。理由: 候補盆地で外挿・乱高下し、最重要地点に最も信用できない数値を与える。
- **(C) 日照時間を主proxyに**。Codexの再定義を採用: 目的を「全天日射エネルギー」から **「明るい屋外光の機会・晴天性・季節安定性」** に寄せ直す。日照時間は直接実測・155点・概日的にも妥当（飽和を踏まえ「明るい時間数」は良い代理）。
- **(B) NEDO METPV-20 等の外部GHIを"監査層"として候補盆地で取得**する方針。GHI≠日照と判明した以上、盆地が*実GHIでも*上位かを確認する価値がある。ただし衛星+ML由来で高地を正しく扱う外部値に限る（自前A–P外挿は不可）。

## 今後 / 最大の見落とし（Codex・構成概念妥当性レンズが一致して指摘）

**平年値(1991–2020気候値)は実際の日々の急変を消している**。「変化率(delta)が重要」仮説に効くのが3〜14日の連続曇天・急落なら、**実日別データで volatility 指標**（7/14/30日の急落、連続低日照日数、回復の急峻さ、冬底の年々信頼性）を出すのが結論を変える本命。推計GHIより遥かに価値が高い → 次フェーズ。

## データソースの現状

現状は**気象庁(JMA)のみ**（obsdl 由来の平年値）。NEDO は新規外部ソース。取得方法・形式・候補地カバレッジ・利用条件を別途調査（→ 調査メモ）。

## NEDO METPV-20 取得調査（2026-06-28）

**致命的な但し書き（期待値の補正）**: NEDOの全国835地点のうち、全天日射量を**実測しているのは47地点(気象官署)のみ**。残り（**松本48361・諏訪48491・軽井沢48331・飯田48767 を含む**）は全て**「日照時間＋気温」からの機械学習推計値**（TXT形式の各値末尾リマーク `9`=推定 / `1`=観測で判別可）。
→ つまり NEDOの盆地GHIも**独立した実測"真値"ではなく、より良い推計**。「実GHIで盆地を監査」という当初の狙いは半分崩れる。ただし我々のA–Pより優れる点は本物:
- **気温を説明変数に使う**（Bristow–Campbell的）→ 松本の放射霧が晴れて極寒快晴になる盆地冬を、日照だけより良く捉える可能性。**まさにA–Pが外した盆地特有の物理**。
- MONSOLA-20(1kmメッシュ)は**ひまわり8号**で空間分布を補完。
- 期間2010–2018、日本気象協会の専門較正、直散分離(Perez/板垣)。
→ 位置づけ修正: NEDO盆地値は「**A–Pより良い"second estimate"**」であって ground truth ではない。推計 vs より良い推計の照合（温度+衛星モデルが日照ランキングと食い違うか）として価値あり。盆地の**best-available GHI推計**として採用候補。

**取得方法**: 公式の一括DL/API/直URLは無し（**対話式ビューアのみ**）。METPV-20は1地点ずつ「1年分のデータをダウンロード」→ CSV/TXT。全835は不可、候補4–8地点なら手動 or ブラウザ自動化(playwright)で地点ループ。
- 地点番号 = 気象庁アメダス5桁。松本48361 / 諏訪48491 / 軽井沢48331 / 飯田48767 / 長野48156 / 甲府49142 / 名古屋51106。
- 形式: 要素1=水平面全天日射量(**0.01 MJ/m²**, 毎時)、日積算は列AE、可照=要素10、気温=要素5。代表年 rm=平均/rw=多照/rc=寡照（月ごとに採用年が変わる人工1年）。
- 入口: <https://appww2.infoc.nedo.go.jp/appww/metpv.html>（この調査環境からはDNS不達＝egress制限の可能性）。
- **ライセンス**: 著作権NEDO。研究個人利用は可の慣行だが、**再配布・商用条件は未確認**（NEDOサイトポリシー要確認）。→ 生データは repo に置かず**派生指標のみ保持**、出典明記「NEDO 日射量データベース(METPV-20)」。

**判断への影響**: NEDOは「独立な真値監査」ではなく「温度＋衛星を使うより良い推計での照合」。それでも盆地の best-available GHI なので、(B)を「盆地4地点を NEDO で取得し、日照ランキングと食い違うか確認」に具体化する価値はある。ただし**真に独立な高地GHIは依然として存在しない**（高地で実測する官署が無い）点は変わらず。
