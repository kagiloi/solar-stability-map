# 実験ノート: 実日別 volatility（1991-2020）— 平年値が消す「連続曇天」

**Date**: 2026-06-28
**Script**: `analysis/daily_volatility.py`（生日別は `data/jma_daily/` にキャッシュ=gitignore、派生は `data/daily_volatility.csv`）
**動機**: 「光の量より変化率(delta)が重要」仮説は、30年*平年値*では検証不能（平滑化が日々の急変・連続曇天・年々変動を消す）。NASA POWERも~100km格子で局所変動を平均化して潰した。→ station解像度の*実観測*日別が必須。

## 手法
JMA obsdl から11地点(盆地4/道東3/太平洋2/日本海2)の実観測日照時間 1991-2020(各~10,955日, 欠測<0.2%)を取得。冬(DJF)について:
- 冬平均日照h、年々CV%(当たり外れ冬)、日々|Δ|、暗い日%(日照<2.0h)、連続暗の最長日数(各冬の最長→30冬の平均と最悪)。

## 発見
1. **日本海は冬「異次元に」悪い**: 冬60%が日照<2h、最長13-14日連続で日が射さない(毎冬平均8日連続)。平年値/NASAでは「やや暗い」程度にしか見えなかった連続曇天の実態。永住除外の確信度が一段上がった。
2. **盆地+静岡は実日別でも堅い**(連続暗5-7日, 暗い日15-22%)= 明るい冬が日照/NEDO/NASA/実日別の4系統で一致。
3. **「道東最強」は平年値アーティファクト**: v2は平年値で道東を最上位にしたが、実日別では釧路/根室は盆地より連続曇天が長く(8日)・暗い日多(根室23.8%)・当たり外れ大(CV10.4)。**帯広だけが本物**。

## 仮説の精緻化（理論的に重要）
- **日々|Δ|は全群フラット(2.3-3.5)** → 「高頻度の変化率」は判別変数でない。
- 効くのは **連続曇天の"持続"** = 「変化率」より「低光状態の継続長(踊り場の長さ)」。仮説をこちらへ寄せる。
- **\|Δ\|は誤誘導**: 日本海はむしろ\|Δ\|が低い=「安定して暗い」。**変動の小ささを単純評価すると日本海を誤って高評価**。v2が floor報酬+非補償(暗い冬は買い戻せない)にした設計が実日別で裏付けられた。

## バイアス上の注意（次ステップへの申し送り）
移住第一候補(松本/諏訪)という*既知の望む答え*がある状態で新指標をv2へ統合する。**「松本最強」に向けて閾値/窓/重みを後付け調整する確証バイアス(garden of forking paths)に陥る危険**。統合の*手法*は独立consultで先に固め、(a)指標定義と重みは結果を見る前に科学的根拠で確定、(b)感度分析で頑健性を示す、(c)候補が落ちても正直に報告、を厳守する。→ 別ノート/ADRに記録予定。

## 統合手法の合意（consult: 私 + Codex 独立収束, 2026-06-28）
確証バイアス回避のための統合方針。**結果を見る前に固定**:
- 指標 = **dark_spell_persistence = CVaR80**（各冬の最長連続暗日数 L_y の worst-20%平均）。季節 **Nov–Mar**。閾値 **2.0h**（機序: 日照=直達光/雲量proxy、<2h=明るい直達ほぼ無し）、**1h/3hで頑健性確認**。
- **重み付き項にしない → risk band(緑/黄/赤) + Pareto軸**として提示（重みは臨床アウトカム不在で推定不能=価値判断。重みを置かねば「松本有利に盛る」過適合が原理的に不可能）。
- 単一スカラーに潰さない。提示順: ①hard filter(医療/生活/雪/暑熱) ②Pareto軸(winter_floor, dark_spell, 遷移, excessTV, amplitude) ③risk band ④任意スカラー ⑤候補は冬分布図/連続暗カレンダー。
- 過適合検出: 閾値振り・bootstrap by winter・期間分割(91-05 vs 06-20)・winter_floor冗長性・leave-one-axis-out・blind reveal・top-decile/Pareto。「#1か」でなく「広い仕様範囲でPareto-efficientに残るか」。
- **仮説更新**: 日々|Δ|(一階差分)は判別力低→格下げ。効いたのは低光状態の自己相関(=回復日が来ない)=**持続**を別軸に昇格。
- 医療上の留保: これは候補を狭める気候スクリーニングであって治療/安全判断の代替でない。冬の低光が本人にどれだけ効くかは主治医と別途。

## 統合結果（全155地点, bias-safe, `dark_spell_integrate.py`）

**頑健性（合格）**: CVaR80 の順位は閾値に不変（t2 vs t1 τ=0.94, t2 vs t3 τ=0.96）、期間分割でも安定（91-05 vs 06-20 τ=0.88）。閾値2hは cherry-pick でない。
**ただし winter_floor と r=−0.88** ＝ **dark-spell は冬の明るさと約77%重複**。隠れた新次元ではなく、主に「明るい冬」を補強する軸（独立な上乗せは~23%＝低光の"持続/自己相関"部分のみ）。
**risk band（事前登録 5/10日, 閾値2h）**: green24 / yellow89 / red42。RED高リスク＝寿都/留萌/深浦/江差/稚内/羽幌/秋田/輪島/相川…＝**日本海側+北海道西岸+冬曇りの南島(与那国)** ＝気象的に連続した空間構造（点状でない＝健全）。

**確証バイアス検出（最重要・合格）**:
- 「明るい&踊り場短い」good集合に5仕様(t1/t2/t3/前半/後半)すべてで残る頑健core=23地点（諏訪/飯田/甲府/静岡/名古屋/帯広/釧路/前橋/熊谷/浜松/岐阜/宮古/仙台…）＝**Pacific側+中部+道東の連続した気候帯**。
- **松本は 4/5（閾値1hで脱落）＝盆地内で最も borderline**。**「松本最強」は作られなかった**。諏訪/飯田/甲府/静岡の方が頑健。→ 指標は望む答えに過適合していない。
- **「道東最強は平年値アーティファクト」も部分的に撤回**: 頑健統計CVaR80で見ると**帯広+釧路は5/5で good core に残る**（根室だけ0/5）。11地点版の「釧路降格」は最悪値1点に引っ張られた過大評価で、ロバスト統計では釧路も良い。v2の道東上位は概ね妥当、根室のみ弱い。

**Pareto は2地点に潰れた**（前橋/岐阜）＝冬明るさ×連続暗×当たり外れの3軸が高相関で**トレードオフが存在しない**（"明るい冬"がほぼ全部を与える）。→ 多軸Paretoより **risk band overlay + 冬明るさ主軸** が正しい提示。

## 統合の決定
- dark-spell は **スカラーへの重み項にしない**（winter_floorと77%重複＝重み付けは冬明るさの二重計上+tuning自由度を生むだけ）。**RED-FLAG overlay**（日本海/北海道西岸/冬曇り南島を警告）として持つ。winter_floor が引き続き master 軸。
- **仮説の最終形**: 「変化率(delta, 一階差分)」は地域選別の判別力ほぼ無し（|Δ|フラット）。効いたのは**冬の絶対的な明るさ**と、それと強相関の**連続曇天の持続**。→ v2の floor中心・非補償設計が実日別で支持された。dark-spell は独立軸でなく floor の red-flag 補強。
