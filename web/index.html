About this project

Purpose: Bipolar disorder symptoms can be influenced by the light environment. This project analyzes JMA (Japan Meteorological Agency) daily normal values to find locations with stable light environments and gentle seasonal transitions, potentially suitable for long-term residence.

Data Sources

SourceDescriptionStations
全天日射量 (solar radiation)Total solar energy, MJ/m²/day. Captures diffuse radiation through clouds.48
日照時間 (sunshine hours)Hours of direct sunshine, h/day. Binary threshold (120 W/m²).155

Default is 全天日射量 (solar radiation) as it better represents the actual light environment. 日照時間 covers 3x more stations but is a binary threshold measure.

Limitations

  • Only normals (平年値) used -- year-to-year variability not captured
  • No livability/population filter applied
  • autumn_30d_drop has weak sunshine-solar correlation (r=0.127)
