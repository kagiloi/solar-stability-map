About this project

Purpose: Bipolar disorder symptoms can be influenced by the light environment. This project analyzes JMA (Japan Meteorological Agency) daily normal values to find locations with stable light environments and gentle seasonal transitions, potentially suitable for long-term residence.

Data Sources

SourceDescriptionStations
全天日射量 (solar radiation)Total solar energy, MJ/m²/day. Captures diffuse radiation through clouds.48
日照時間 (sunshine hours)Hours of direct sunshine, h/day. Binary threshold (120 W/m²).155

Default is 全天日射量 (solar radiation) as it better represents the actual light environment. 日照時間 covers 3x more stations but is a binary threshold measure.

Scoring models

v2 (default) — 非補償・絶対基準: データ衛生（南極の昭和基地を除外）→ 各指標を固定アンカーで desirability [0,1] に（z スコアをやめサンプル非依存に）→ augmented weighted Chebyshev score_v2 = maxj wj(1−dj) + ρ·Σ で集約（弱い軸が支配＝floor と delta を交換不可に）。 根拠: 春の日射変化率が双極I型の発症年齢と関連（Bauer ら多施設, PMID 28722128）／冬の光は 飽和するのでハード閾値でなく凹型ペナルティ（Zeitzer 2000, PMID 10922269）。詳細は docs/adr/004_phase2-scoring-v2.md。
v1 — 線形 z 和: 各指標 z スコアの重み付き和。補償型でサンプル依存。比較用に残置。

Limitations

  • 平年値 + 15日平滑のため total_variation は「実生活の変動」ではなく「季節傾き + 梅雨構造」。総観スケール（連続曇天）・年々変動は捕捉できない（真の変動には日別生データが必要）。
  • 居住可能性フィルタ未適用（南鳥島・父島など無人島が上位に出る）。
  • 重み・アンカー・k・ρ は判断レバー。感度分析は今後。
  • autumn_30d_drop は sunshine-solar 相関が弱い (r=0.127)。

Data Source

Japan Meteorological Agency (気象庁) daily normals, crawled from 過去の気象データ・ダウンロード.

指標の説明

スコアは低いほど良い。ほとんどの指標は気象庁の30年平年値を15日平滑した曲線から算出。 冬リスク・連続曇天・冬の実日照・当たり外れだけは実観測の日別1991-2020から。 単位はソースで変わる(日照時間=時間/日, 全天日射=MJ/m²/日)。候補検討は松本/諏訪を含む日照時間(155地点)ソースで。
